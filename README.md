# RBX BLOXSTRIKE Platform

Официальный веб-сайт турнирного оператора **RBX BloxStrike**.

## Особенности
- **Дизайн без сторонних брендов**: Строгий серо-синий игровой стилистический интерфейс.
- **Поддержка тем**: Тёмная (Серо-синяя) и Светлая (Бело-желтая).
- **Админ-панель**: Встроенная панель (пароль по умолчанию: `admin123`) для управления матчами, сеткой, настройками и заявками.
- **Двуязычность**: Переключение языков RU 🇷🇺 / EN 🇬🇧.
- **Готовность к хостингу**: Полностью автономен, запускается на Render, GitHub Pages, Vercel и других сервисах.

## Инструкция по деплою на Render / GitHub Pages

### GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите файлы из этого архива.
3. В настройках репозитория (Settings -> Pages) выберите ветку `main` и сохраните.

### Render.com
1. Создайте новый **Static Site** на Render.
2. Подключите ваш репозиторий GitHub.
3. Оставьте поля Build Command пустыми, а Publish Directory укажите `./`.
4. Нажмите **Create Static Site**.
